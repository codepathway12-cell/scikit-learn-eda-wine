# Wine Dataset — Exploratory Data Analysis (EDA)

A complete EDA on the classic Wine dataset using NumPy, Pandas,
Matplotlib, Seaborn, and Scikit-learn.

## What's inside

- `EDA_wine.ipynb` — full notebook with 18+ charts
- `requirements.txt` — Python dependencies

## How to run it

### 1. Clone the repository

```bash
git clone https://github.com/codepathway12-cell/scikit-learn-eda-wine.git
cd wine-eda
```
